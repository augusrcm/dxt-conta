    1. Finalidad del módulo

    Este módulo permite ejecutar el proceso formal de cierre de una gestión contable, abrir la gestión siguiente y reabrir una gestión cerrada cuando corresponde.

    Las operaciones generan o anulan comprobantes contables y actualizan el control de gestión. Por eso deben ejecutarse solo cuando la información contable ya fue revisada.

    2. Flujo recomendado

    1. Seleccione la gestión origen.
    2. Revise el estado, el balance y la cuenta resultado del ejercicio.
    3. Ejecute Validar cierre.
    4. Si la validación es correcta, ejecute Ejecutar cierre.
    5. Ejecute Validar apertura.
    6. Si la validación es correcta, ejecute Ejecutar apertura.

    3. Cuenta resultado del ejercicio

    La cuenta configurada debe ser patrimonial, activa y postable. El sistema la usa para registrar la utilidad o pérdida neta al momento del cierre.

    • Revísela antes de cerrar la gestión.
    • No use cuentas de ingreso, costo, gasto, activo o pasivo.
    • Después de cambiarla, presione Guardar.

    4. Cierre de gestión

    El cierre cancela las cuentas temporales de ingresos, costos y gastos, y traslada el resultado neto a la cuenta patrimonial configurada.

    • La gestión debe estar abierta.
    • El balance debe estar cuadrado.
    • No debe existir un cierre confirmado previo para la misma gestión.
    • No debe existir un bloqueo crítico activo.

    5. Apertura de gestión

    La apertura traslada a la nueva gestión los saldos de balance: activo, pasivo y patrimonio. No traslada cuentas de ingresos, costos ni gastos.

    • La gestión origen debe estar cerrada.
    • Debe existir comprobante de cierre confirmado.
    • La gestión destino no debe tener una apertura previa.
    • La gestión destino no debe tener movimientos confirmados que impidan una apertura limpia.

    6. Reapertura de gestión

    La reapertura se usa cuando una gestión cerrada necesita corrección. El sistema anula el cierre y, si corresponde, también la apertura relacionada.

    Para reabrir es obligatorio registrar una observación clara. Esa observación queda como respaldo en la bitácora del proceso.

    7. Estado, historial y bloqueos

    • Estado: muestra si la gestión origen está abierta o cerrada.
    • Balance: indica si la gestión está cuadrada.
    • Bloqueo: indica si hay un proceso crítico en ejecución.
    • Historial: registra validaciones, cierres, aperturas, fallos y reaperturas.
