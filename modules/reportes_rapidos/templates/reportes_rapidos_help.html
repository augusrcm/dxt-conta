Uso de la interfaz

  • El área de menú permite cambiar de reporte sin salir de la pantalla.
  • El área de filtros actualiza los resultados automáticamente al cambiar periodo, fecha, estado o unidad.
  • El área de resultados conserva la tabla anterior mientras se actualiza para evitar pantallas en blanco.
  • Use Excel para análisis detallado y PDF para impresión o revisión ejecutiva.

Totales

Los totales se muestran cuando el reporte trabaja con una moneda única o con moneda base definida. Si el reporte contiene varias monedas, el sistema prioriza totales por moneda o evita mezclar importes.
