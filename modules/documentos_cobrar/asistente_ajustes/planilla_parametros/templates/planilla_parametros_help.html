Parámetros de Planilla

Define la configuración anual que usará la generación mensual de planillas. Se registra una vez por gestión y solo se ajusta cuando cambian valores normativos, criterios internos o cuentas contables.

Parámetros laborales
  • Salario mínimo nacional.
  • Base para bono de antigüedad.
  • Porcentaje AFP/Gestora.
  • Jornada semanal referencial.
  • Múltiplo referencial para RC-IVA.
Cuentas contables
  • Use Sugerir cuentas para cargar cuentas del plan actual.
  • El contador puede cambiar cualquier cuenta sugerida.
  • La planilla mensual no vuelve a pedir estas cuentas.
  • Si falta una cuenta requerida, el sistema bloquea la consolidación antes de generar asientos.
Copiar gestión anterior

Permite iniciar una nueva gestión tomando como base la configuración activa más reciente. Revise y ajuste solo lo necesario antes de guardar.
