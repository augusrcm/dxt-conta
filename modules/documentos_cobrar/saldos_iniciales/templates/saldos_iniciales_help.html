Saldos Iniciales

Esta pantalla sirve para registrar el punto de partida del sistema contable cuando la empresa empieza a usar DXT-Conta. No es cierre de gestión y no es apertura automática de una nueva gestión.

Cuándo usarla

Úsela una sola vez al iniciar la contabilidad en el sistema, o para corregir esos importes mientras la gestión permanezca abierta.

Reglas principales

  • Cada línea debe tener una unidad de negocio.
  • Solo se permiten cuentas activas, postables y de balance: Activo, Pasivo o Patrimonio.
  • Una línea puede tener Debe o Haber, pero no ambos.
  • Cada unidad de negocio debe cuadrar por separado: total Debe igual a total Haber.
  • Si una cuenta exige auxiliar o centro de costo, debe seleccionarse antes de guardar.

Qué genera el sistema

Al guardar, el sistema crea o actualiza comprobantes contables especiales con origen SALDOS_INICIALES. Internamente se genera un comprobante por cada unidad de negocio que tenga líneas cuadradas.

Modificaciones

Si la gestión está abierta, puede corregir importes o cuentas desde esta misma pantalla. Si la gestión está cerrada, no se permite modificar directamente los saldos iniciales: corresponde reabrir la gestión o registrar un asiento de ajuste posterior.

Reporte y respaldo

Después de guardar, puede emitir el PDF para revisión, archivo o firma. También puede descargar el Excel cuando necesite revisar, filtrar o conservar el detalle completo de las líneas.

Recomendación operativa

Antes de guardar, revise el bloque de control de cuadratura. Si una unidad aparece con diferencia, debe corregir sus líneas antes de procesar. Luego emita el PDF como respaldo formal de los importes iniciales cargados.
