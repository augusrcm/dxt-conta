Conciliación Caja/Banco

Esta herramienta revisa cajas y cuentas bancarias para ayudar a detectar saldos que requieren atención antes de emitir reportes o tomar decisiones de tesorería.

Qué revisa

  • Saldo según operaciones confirmadas hasta la fecha de corte.
  • Último arqueo de caja y diferencia registrada.
  • Operaciones en borrador que podrían modificar el saldo.
  • Operaciones confirmadas sin asiento contable relacionado.
  • Cajas o bancos con saldo negativo.

Cómo usarla

  1. Seleccione la fecha de corte.
  2. Filtre por caja, banco o todos.
  3. Seleccione una unidad de negocio si necesita revisar una sola unidad.
  4. Revise las prioridades y la acción sugerida.
  5. Use PDF para respaldo y Excel para análisis detallado.

Reglas importantes

  • La herramienta no modifica datos ni registra movimientos.
  • El saldo del sistema se calcula con cobros, pagos y movimientos de tesorería confirmados.
  • Para bancos, el sistema no reemplaza el extracto bancario externo; solo muestra el saldo contable-operativo del sistema.
  • Las diferencias de caja dependen del último arqueo registrado.
