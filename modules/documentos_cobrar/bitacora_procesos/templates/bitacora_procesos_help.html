Bitacora de Procesos

Esta herramienta centraliza la consulta de procesos especiales y eventos criticos del sistema.

Que muestra

  • Cierres, aperturas, reaperturas y validaciones registradas.
  • Backups pre-cierre y respaldos registrados.
  • Restauraciones de backup.
  • Bloqueos criticos generados durante procesos delicados.

Como usarla

  • Seleccione gestion, fechas, fuente, tipo de proceso y estado.
  • Revise las prioridades altas o criticas antes de ejecutar cierres o restauraciones.
  • Use PDF para documentar la revision y Excel para analisis o archivo externo.

Importante

  • Este modulo es solo de consulta.
  • No ejecuta cierres, aperturas, backups ni restauraciones.
  • No modifica registros existentes.
  • La informacion proviene de las bitacoras y tablas de procesos criticos del sistema.
