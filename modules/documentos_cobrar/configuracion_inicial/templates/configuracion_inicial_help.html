    1. ¿Cuándo usar esta pantalla?

    Esta pantalla se usa cuando el sistema todavía no tiene una base operativa completa. Su función es dejar definida la gestión inicial de trabajo, registrar la primera unidad de negocio y dejar lista la cuenta patrimonial del resultado del ejercicio.

    No reemplaza el proceso normal de cierre y apertura de gestión. Tampoco reemplaza el control diario de tipo de cambio de SUS y UFV.

    2. Datos principales

    Gestión inicial

    Es la gestión que quedará habilitada como base para empezar a trabajar.

    Primera unidad de negocio

    Debe registrarse al menos una unidad real para arrancar el sistema. El nombre lo define el operador y el código se genera automáticamente.

    Cuenta patrimonial

    Debe ser una cuenta activa, postable y de tipo PATRIMONIO.

    Glosa de cierre

    Texto base que el sistema utilizará en el comprobante contable del cierre.

    Glosa de apertura

    Texto base que el sistema utilizará en el comprobante contable de apertura.

    3. Reglas operativas

    Permitir reapertura

    Autoriza volver a abrir una gestión cerrada cuando exista una causa válida.

    Bloquear si hay borradores

    Evita procesos de gestión cuando aún existen documentos sin confirmar.

    Bloquear si hay movimientos en destino

    Protege la siguiente gestión para que no existan registros previos antes de su apertura.

    4. Flujo recomendado

    1. Selecciona la gestión inicial con la que realmente comenzarás a operar.
    2. Si todavía no existe ninguna, registra la primera unidad de negocio con el nombre real que usarás en operación.
    3. Elige la cuenta patrimonial del resultado del ejercicio.
    4. Revisa las glosas y las reglas operativas.
    5. Guarda la configuración y continúa con el trabajo normal del sistema.

    5. Primera unidad de negocio

    El sistema ya no depende de un registro precargado en base de datos. Si todavía no existe ninguna unidad, esta pantalla te pedirá crear la primera desde la propia interfaz.

    El nombre debe corresponder a una unidad real de trabajo. El NIT es opcional en esta pantalla y el código se genera automáticamente al guardar.

    6. Relación con el tipo de cambio del día

    Aunque la configuración inicial deje lista la estructura del sistema, el usuario seguirá viendo el control diario bloqueante de tipo de cambio cuando falten SUS y UFV para la fecha operativa actual.
